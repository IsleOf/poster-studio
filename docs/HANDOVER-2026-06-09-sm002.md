## Gotchas locked in (don't regress)
- **Export path embeds images.** `renderPoster.ts embedImages()` inlines external `<image>` hrefs as
  base64 before serializing — without it the forest background drops from the Download Preview / saved
  PNG/PDF (blob-URL SVG can't resolve relative hrefs) while the DOM preview still shows it. ALWAYS test
  the export path (Download Preview → PNG), not just the editor preview.
- No horizontal over-scale on the background image (crops trees L/R).
- Re-run `sync-listing-state.cjs` after any scaffolder run (thumbnail_path nulling).
- Set example dates on the top-level `date` field, never `customText.date` (applyTemplate wipes it).
- Deploy frontend with `--exclude='designs/' --exclude='backgrounds/'` (rsync --delete would wipe
  the asset dirs that aren't build artifacts).
